# 🚀 Team Task Manager

A modern task management platform designed to help teams collaborate, manage projects, assign tasks, and track progress efficiently.

Live Preview:  
https://ai.studio/apps/26eb9c60-414f-4538-b443-b727564937b6

</div>

---

## 📌 Features

- User Authentication (Login / Signup UI)
- Role-Based Dashboard (Admin & Member)
- Project Management
- Task Assignment & Tracking
- Progress Monitoring
- Analytics Dashboard
- Notifications System
- Responsive Design
- Modern UI with Smooth Animations

---

## 🛠 Tech Stack

Frontend technologies used:

- React + Vite
- TypeScript
- TailwindCSS
- React Router
- Framer Motion
- Zustand / Context API
- Recharts
- React Hook Form
- Zod Validation

## ⚙️ Run Locally

### Prerequisites

Install:

- Node.js
- npm

Verify installation:

```bash
node -v
npm -v
```

---

### 1. Clone Repository

```bash
git clone <repository-url>
cd project-folder
```

---

### 2. Install Dependencies

```bash
npm install
```

---

### 3. Configure Environment Variables

Create:

```bash
.env.local
```

Add:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Get API key from:

https://aistudio.google.com/

---

### 4. Start Development Server

Run:

```bash
npm run dev
```

Open:

```bash
http://localhost:5173
```
